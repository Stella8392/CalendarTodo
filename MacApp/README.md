# Mac 预览版

Mac 版正在开发和验证中，分别提供 Apple 芯片（osx-arm64）和 Intel（osx-x64）构建。目标系统为 macOS 14 或更新版本，自动验证使用 macOS 15。正式发布前还需人工验证窗口交互、通知显示和真实邮箱登录。

## 安装

从通过验证的 macOS preview 工作流下载与芯片匹配的预览附件，解压 CalendarTodo.app，将应用拖入「应用程序」后打开。应用自带 .NET 运行时。Apple 芯片选 osx-arm64，Intel 选 osx-x64。

预览包采用本地 ad-hoc 签名，尚未使用 Apple Developer ID 签名和公证。首次打开可能被系统拦截，可在系统「隐私与安全性」中查看该应用的提示并决定是否允许。请核对下载来源和 SHA256SUMS.txt。

## 使用

- 按住标题拖动，拖动窗口边缘或角调整大小。上下拖动日程与待办之间的分隔条，调整日程区高度。
- 点日历日期查看当天日程，日期角标显示事件数量。右键单条日程或待办可确认删除。
- 「今日待办」按北京时间筛选，勾选后划线并排到列表底部。未来日期的日程在当天进入今日待办。
- 在「设置」中逐个绑定 163、QQ 或 Gmail 账号。填写完整邮箱账号和自己的授权码或应用专用密码，连接成功后保存。每个账号的凭据保存在本机 macOS 钥匙串，邮件在本机解析。
- 每日同步默认北京时间 20:00，可在设置调整。点「同步」手动增量同步，进行中可取消。
- 「隐藏」后从 macOS 顶部菜单栏图标唤回，关闭窗口或点菜单「退出」会退出应用，后台同步与提醒随之停止。
- 预览版通过系统 AppleScript 请求显示提醒，实际可见性取决于系统通知权限。系统可能将通知归入脚本执行组件，需在 Mac 上人工确认。
- 将应用放到固定位置后，可在设置开启「登录 Mac 后启动」。更改应用位置后请重新保存此设置。
- 「反馈」打开公开 GitHub Issues，由用户检查后提交。请避免包含授权码、邮箱账号和私人日程。

QQ 官方授权码入口与各渠道完整教程见仓库首页的「多邮箱授权与同步」部分。 [查看授权教程](https://github.com/Stella8392/CalendarTodo#多邮箱授权与同步)

## 数据

日程和待办保存在 ~/Library/Application Support/CalendarTodo/widget.db，可通过 CALENDARTODO_DATA_DIR 自定义目录。数据包含私人记录，请勿公开分享。解除单个邮箱绑定会移除该账号的钥匙串凭据，保留已导入日程。

Mac 和 Windows 安装各自保存本地数据，当前没有跨设备云同步。开发者在 Windows 电脑上的构建、缓存和测试文件保存在 F 盘。

## 构建

在 Mac 上安装 .NET 10 SDK 后，运行 bash MacApp/Build.sh osx-arm64 或 bash MacApp/Build.sh osx-x64。结果在 dist/mac 对应目录。自动化工作流分别在两种芯片的 Mac 上运行核心回归检查、打包和启动检查，并验证钥匙串的新增、读取、更新和删除。
